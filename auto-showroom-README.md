# 🚗 AutoShowroom

> A modern car dealership mobile app built with Flutter — browse, filter, and connect with showrooms.

> 🚀 **Coming soon to Google Play Store**

---

## 📱 Overview

AutoShowroom is a Flutter mobile application designed for car dealerships and their customers. It provides a seamless experience for browsing vehicle inventory, filtering by specs and price, and directly connecting with showroom agents.

---

## ✨ Features

- 🚘 Full vehicle inventory browsing
- 🔍 Advanced filtering (brand, model, year, price, mileage)
- 📸 High-quality vehicle image galleries
- 📞 Direct contact with showroom agents
- ❤️ Save favorite vehicles
- 📊 Vehicle comparison tool
- 📍 Showroom location and directions

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| Flutter | Cross-platform mobile app |
| Dart | Programming language |
| REST APIs | Vehicle inventory data |
| SQLite | Local favorites storage |
| Provider | State management |

## 🚀 Getting Started

### Prerequisites
- Flutter SDK >= 3.0.0
- Dart >= 3.0.0

### Installation

```bash
# Clone the repository
git clone https://github.com/IbraheemKayed/auto-showroom.git

# Navigate to project directory
cd auto-showroom

# Install dependencies
flutter pub get

# Run the app
flutter run
```
